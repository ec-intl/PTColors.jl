API Reference

This page documents the public constants, functions, and macros exported by PTColors.

Module

PTColors.PTColors — Module
module PTColors

A lightweight Julia module providing color-coded, timestamped terminal messages.

Exports

  • defaultmsg(msg, typ, color): Print a timestamped message with an optional ANSI color.
  • headermsg(msg): Print a notice message with a bright magenta status label.
  • infomsg(msg): Print an information message with a bright blue status label.
  • okmsg(msg): Print a success message with a bright green status label.
  • warnmsg(msg): Print a warning message with a bright yellow status label.
  • failmsg(msg): Print a failure message with a bright red status label.
  • messages(...): Run a callback with information, success, and failure messages.
  • @ptok, @ptinfo, @ptwarn, @pterror: Convenience macros for colored messages.

All functions print to standard output by default with a consistent format and ANSI color codes. No dependencies required.

Color constants

These constants contain ANSI Select Graphic Rendition (SGR) escape sequences that instruct compatible terminals to select bright foreground color categories or reset formatting. They do not define fixed RGB values, so the exact rendered shades depend on the terminal emulator and its active color theme.

PTColors.HEADER — Constant

HEADER: ANSI bright magenta foreground code for header messages. Example: println(HEADER * "Header text" * ENDC)

PTColors.INFO — Constant

INFO: ANSI bright blue foreground code for information messages. Example: println(INFO * "Info text" * ENDC)

PTColors.OKGREEN — Constant

OKGREEN: ANSI bright green foreground code for success messages. Example: println(OKGREEN * "Success text" * ENDC)

PTColors.WARNING — Constant

WARNING: ANSI bright yellow foreground code for warning messages. Example: println(WARNING * "Warning text" * ENDC)

PTColors.FAIL — Constant

FAIL: ANSI bright red foreground code for failure messages. Example: println(FAIL * "Failure text" * ENDC)

PTColors.ENDC — Constant

ENDC: ANSI code to reset color formatting. Example: println(HEADER * "Header" * ENDC)

Timestamp and message formatting

PTColors.timestamp — Function

timestamp()

Return the current date and time as a formatted string for log messages. Format: yyyy-mm-dd HH:MM:SS

Example: ts = timestamp() println(ts)

PTColors.defaultmsg — Function

defaultmsg(msg, typ=" NOTICE ", color=nothing; io=stdout)

Print a timestamped message. When color is supplied, it is applied to the type label.

Example: defaultmsg("Hello!", "INFO", INFO) defaultmsg("No color label")

Callback handling

PTColors.messages — Function

messages(infomsg, successmsg, failure_msg, callback, args...; exception=Exception, io=stdout, kwargs...)

Print info_msg, run callback(args...; kwargs...), then print either success_msg or failure_msg. Returns 0 when the callback succeeds and 1 when it throws the expected exception type. Unexpected exceptions are rethrown.

exception can be a single exception type or a tuple of exception types.

Example: messages("Starting...", "Done!", "Failed!", x -> println(x), "Hello")

Convenience macros

PTColors.@pterror — Macro

@pterror msg Print a failure message with a timestamp and a bright red status label. Example: @pterror "Failed to load module."

PTColors.@ptinfo — Macro

@ptinfo msg Print an information message with a timestamp and a bright blue status label. Example: @ptinfo "Simulation started."

PTColors.@ptok — Macro

@ptok msg Print a success message with a timestamp and a bright green status label. Example: @ptok "Module loaded successfully."

PTColors.@ptwarn — Macro

@ptwarn msg Print a warning message with a timestamp and a bright yellow status label. Example: @ptwarn "Configuration file missing."
